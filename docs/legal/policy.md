# Legal policy

ZenithPS5 is an emulator written from scratch. To stay that way:

## What is never in this repository

- Sony firmware, system software, libraries or code, in any form (binary, dump, extract, decompiled or
  transcribed).
- Encryption keys, signing keys or any other secret.
- Commercial games, or any part of them (executables, assets, shaders, textures, symbols, logs that contain
  such content).

Contributions that contain such material are rejected, and removed from the history if they slip in. Test
programs are written for this project, or freely distributable.

## What the project does not do

- It does not decrypt or unsign software, and does not circumvent the protections of any console.
- It does not help with obtaining software illegitimately. Issues and discussions that ask for it are closed.

Users are expected to run software they obtained legally, and to run it on hardware they own.

## How system behavior is learned

HLE functions are implemented from public information, from the behavior of freely distributable test
programs, and from the observable results of the code we write ourselves. Do not paste code, dumps or
disassembly of Sony software into issues, pull requests or commits.
